## Overview

Token Use is a focused fork of [CC Switch](https://github.com/farion1231/cc-switch). It removes the provider switching, multi-tool configuration, MCP, prompt, skill, proxy, and sync surfaces from CC Switch and keeps the part that matters for this product: token usage collection and readable local usage analytics.

The app is designed as a lightweight macOS menu bar and desktop app:

- local-first token usage statistics
- compact menu bar number for today's usage
- separate Usage and Leaderboard views
- optional GitHub login for public ranking
- opt-in ranking only
- ranking windows for today, 7 days, and 30 days
- self-hostable leaderboard backend

Token Use currently focuses on macOS. The inherited codebase still contains cross-platform build scaffolding from CC Switch, but the product and UI decisions in this fork are macOS-first.

## Why Token Use

AI coding tools make it easy to consume a large number of tokens without noticing the trend. Token Use gives you a small, quiet surface for the questions that matter during daily work:

- How many tokens did I use today?
- How did the last 7 or 30 days compare?
- How much of my usage came from input, output, cache reads, and cache creation?
- Do I want to compare my usage with other opted-in users?

The app intentionally avoids account switching and provider management. It is a usage monitor, not an AI gateway.

## Features

### Local Usage

- Reads the same local usage sources inherited from CC Switch.
- Aggregates usage into today, 7-day, and 30-day windows.
- Shows total tokens, request count, cost estimate, cache hit ratio, and token breakdown.
- Keeps usage and request history local by default.
- Displays today's token count in the macOS status bar using compact units such as `999`, `1.2K`, `12.4M`, and `1.2B`.

### Leaderboard

- Uses GitHub Device Flow login.
- Requires login before the leaderboard is visible.
- Requires explicit opt-in before the user's usage is included in ranking.
- Separates ranking from local statistics in the UI.
- Ranks by total token consumption:
  - input tokens
  - output tokens
  - cache read tokens
  - cache creation tokens
- Supports today, 7-day, and 30-day ranking windows.

### Backend

- Small Node.js HTTP service with no runtime npm dependencies.
- Docker-first deployment.
- JSON-file persistence by default for a lightweight first version.
- Public deployment target used by the app: `https://token-use.lucsun.cn`.
- Container port: `6655`.

## Quick Start

### Requirements

- macOS 12 or later
- Node.js 20 or compatible
- pnpm
- Rust 1.85 or later
- Tauri 2 prerequisites for macOS

### Install Dependencies

```bash
pnpm install
```

### Run the App in Development

```bash
pnpm dev
```

### Build the macOS App

```bash
pnpm build
```

Build outputs:

```text
src-tauri/target/release/bundle/macos/Token Use.app
src-tauri/target/release/bundle/dmg/Token Use_0.1.0_aarch64.dmg
```

## Leaderboard Backend

The app defaults to:

```text
https://token-use.lucsun.cn
```

You can override it at runtime:

```bash
TOKEN_USE_BACKEND_URL=http://127.0.0.1:6655 pnpm dev
```

### Run Locally

```bash
cd backend
docker compose up -d --build
curl http://127.0.0.1:6655/healthz
```

### Deploy to the Current Server

The repository includes a deployment script for the current backend host:

```bash
REMOTE_USER=root ./scripts/deploy-token-use-backend.sh
```

Defaults:

- host: `10.31.0.10`
- remote directory: `/opt/token-use-backend`
- public domain: `https://token-use.lucsun.cn`
- container port: `6655`

### API Surface

```text
GET  /healthz
POST /api/github/device/start
POST /api/github/device/poll
GET  /api/me
POST /api/me/opt-in
POST /api/leaderboard/snapshot
GET  /api/leaderboard?range=today|7d|30d
```

All endpoints except health check and GitHub Device Flow start/poll require:

```text
Authorization: Bearer <token>
```

## Privacy Model

Token Use is local-first.

- Local usage statistics stay on the device unless the user logs in and opens the leaderboard flow.
- The leaderboard is opt-in.
- If a user opts out, their profile remains authenticated locally but they are not included in ranking results.
- Ranking snapshots upload aggregate token counts for the selected windows, not raw request logs.
- GitHub login is used only for identity in ranking.

## Configuration

Useful environment variables:

| Variable | Purpose |
| --- | --- |
| `TOKEN_USE_BACKEND_URL` | Override the leaderboard backend URL used by the desktop app. |
| `TOKEN_USE_GITHUB_CLIENT_ID` | Override the GitHub OAuth Client ID used by the desktop app or backend. |
| `TOKEN_MONITOR_GITHUB_CLIENT_ID` | Temporary compatibility fallback for older local builds. |
| `PORT` | Backend HTTP port. Defaults to `6655`. |
| `DATA_DIR` | Backend data directory. Defaults to `/data`. |
| `DATA_FILE` | Backend JSON store path. Defaults to `/data/token-use-backend.json`. |
| `CORS_ORIGIN` | Backend CORS origin. Defaults to `*`. |
