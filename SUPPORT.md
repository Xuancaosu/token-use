# Support

Token Use is an early macOS-first fork of CC Switch focused on local token usage statistics and optional leaderboard ranking.

## Before Asking

Please check:

- [README.md](README.md)
- [README_ZH.md](README_ZH.md)
- [backend/README.md](backend/README.md)
- [docs/usage-only-implementation-notes.md](docs/usage-only-implementation-notes.md)

## Issues

Use GitHub Issues for:

- app crashes
- incorrect usage totals
- GitHub login failures
- leaderboard opt-in or ranking bugs
- backend deployment problems
- documentation gaps

Include:

- Token Use version or commit
- macOS version
- whether this is a local app issue or backend issue
- reproduction steps
- screenshots or logs when helpful

## Security

Do not report vulnerabilities in public issues. Use the process in [SECURITY.md](SECURITY.md).
